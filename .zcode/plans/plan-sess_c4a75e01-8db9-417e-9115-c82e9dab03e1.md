# Docusaurus → Astro 迁移方案（v5 终稿）

## 决策总览
- **框架**：Astro + `@astrojs/sitemap` + `@astrojs/rss`。无 `@astrojs/mdx`、无 React。所有 `.mdx` 弃用。
- **内容**：blog 3 篇 + docs（dotnet/fem/linux/python/tools），删除 `docs/python/interactive-solver/`（SolverUI）。
- **URL**：不强制兼容旧路由；统一 slug 工具管理。**不强行追求线上绝对无尾斜杠**，只保证 Astro 内部规范一致。
- **删除功能**：`/blog/tags/*`、`/blog/archive`、`/blog/authors`、`/docs/category/*`、`/en/*`、`/markdown-page`、3 个 undraw SVG、docusaurus.png。
- **主题**：移植 Claude 风。
- **迁移方式**：新分支 `astro-migration`，**PR 只校验不部署**，合并 main 才部署。

## 版本与依赖
- 不预设 Astro 主版本。`npm install` 后**以 lockfile 锁定的版本及其 Content Layer API 为准**写 `content.config.ts`。
- 核对 Astro 的 `engines.node`：若要求 > 20，同步改 `actions/setup-node`、`package.json#engines` 并告知本地升级；否则保持 Node 20。
- 依赖：`astro`、`@astrojs/sitemap`、`@astrojs/rss`。
- dev 依赖：`@astrojs/check`、`typescript`、`vitest`。
- `tsconfig.json`：`{ "extends": "astro/tsconfigs/strict" }`。
- `package.json` scripts：`check`(astro check)、`test`(vitest run)、`build`(astro build)、`dev`、`preview`。

## 关键修正（v4 + 你 3 点）

### 1. 主题脚本 fallback 修正（localStorage 抛错后仍读系统主题）
Base 的 `<head>` 内：
```astro
<script is:inline>
  let theme = null;
  try {
    theme = localStorage.getItem('theme');
  } catch {}
  theme ||= matchMedia('(prefers-color-scheme: dark)').matches
    ? 'dark'
    : 'light';
  document.documentElement.dataset.theme = theme;
</script>
```
ThemeToggle 组件写入 localStorage 时**单独 try/catch**（隐私模式/存储受限不抛错）。

### 2. workflow 复杂字段用块状 YAML（避免 `${{ }}` 与行内对象解析问题）
```yaml
on:
  push:
    branches: [main]
  pull_request:

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
        with:
          fetch-depth: 0
      - uses: actions/setup-node@v4
        with:
          node-version: 20
          cache: npm
      - run: npm ci
      - run: npm run check
      - run: npm run test
      - run: npm run build
      - name: Upload Build Artifact
        if: github.event_name == 'push'
        uses: actions/upload-pages-artifact@v3
        with:
          path: dist

  deploy:
    if: github.event_name == 'push' && github.ref == 'refs/heads/main'
    needs: build
    permissions:
      pages: write
      id-token: write
    environment:
      name: github-pages
      url: ${{ steps.deployment.outputs.page_url }}
    runs-on: ubuntu-latest
    steps:
      - id: deployment
        uses: actions/deploy-pages@v4
```

### 3. trailingSlash 验收务实化（不强行 build.format:'file'）
保留 `astro.config.mjs` 的 `trailingSlash: 'never'`，让 Astro 内部链接、canonical、RSS、sitemap 统一无尾斜杠。**但承认 GitHub Pages 可能把目录型 URL 重定向为带 `/`**，最终形式以线上实际响应为准。
- 不为追求绝对无尾斜杠而改 `build.format: 'file'`（会带来其他副作用）。
- 验收只要求：**Astro 内部规范一致 + 线上无循环重定向**。

### 4. Vitest 进入 CI（覆盖 5 组 slug）
`src/tests/routes.test.ts`：
```

dotnet/win7net48/win7net48  → /docs/dotnet/win7net48
```

不搬：`undraw_docusaurus_{mountain,react,tree}.svg`、`docusaurus.png`。
favicon 仍用 `/img/favicon.ico`，不复制到根。

### 6. admonition 全路径 + 完整 HTML
- `docs/dotnet/win7net48/win7net48.md` ×2（warning）
- `docs/fem/freecad_build/freecad_build.md` ×3（info）
- `docs/linux/gitlab_deploy/gitlab_deploy.md` ×2（note）+ ×1（tip）

转 `<aside class="admonition admonition-<type>">`，内容含 Markdown 格式时**完整写成 HTML**（`<p>`/`<code>`/`<a>` 等）。

### 7. 新增 `/docs` 入口页
`src/pages/docs/index.astro`：展示 `intro` + 五分类入口。Navbar 与首页按钮统一指向 `/docs`。

### 8. 补 title + 删重复 H1
- `docs/intro.md`：补 `title: "📚 破破文档"`，删正文 `# 📚 破破文档`。
- `docs/linux/arch.md`：补 `title: Arch Linux`、`position: 10`、`description`，删正文 `# Arch Linux`。
- 全量排查其余 docs，凡布局输出 title 又有正文 H1 的一律删 H1。

### 9. 排序字段统一 `position`，合并 `_index.md`
- `sidebar_position`/`weight`/新 `position` → 全部归一为 `position`。
- docs schema：`title: z.string()`、`description: z.string().optional()`、`position: z.number().optional()`。
- 排序：① 有 position 在前 → ② position 升序 → ③ 无 position 按 title → ④ `_index` 仅作分类入口，不出现在子项列表。
- **合并而非覆盖**：以现有 `_index.md` 为底，合并对应 `_category_.json` 的 `label`(→title)、`position`、`description`，然后删 `_category_.json`。
- 修 `fem`(4) 与 `python`(4) 冲突，重编号：dotnet=2, linux=3, fem=4, python=5, tools=6。
- `docs/tools/` 新增 `_index.md`（position 最大）。

### 10. slug 工具契约（`lib/routes.ts`）
返回站点绝对路径：去首尾 `/`、去 `.md`、去掉与父目录同名的末段、`_index`/`index` 映射到目录、禁止 `//` 与意外尾斜杠。
canonical：`new URL(getDocPath(entry), Astro.site)`。canonical/RSS/sidebar/getStaticPaths 共用同一工具。

### 11. RSS 路由
`astro.config.mjs` 只集成 `sitemap()`；`src/pages/rss.xml.ts` 导出 `GET`，内部 `getCollection('blog')` + `rss()`。

### 12. blog frontmatter
- `2025-11-06-intro.md` → `intro.md`，补 `date: 2025-11-06`。
- schema `date: z.coerce.date()`。
- `authors: [ppy]` 由 `data/authors.ts` 按 id 解析。
- 阅读时长由 `lib/reading-time.ts` 构建期算（中文按字数）。
